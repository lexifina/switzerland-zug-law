# § 1
1 Für eine moderne Zuger Kantonsgeschichte wird zulasten der Erfolgsrechnung ein Objektkredit von 6,995 Millionen Franken bewilligt. Dieser Betrag erhöht sich um die MWST der MWST-pflichtigen Leistungen (maximal 8,1 % von 6,995 Millionen Franken: 566 595 Franken).
2 Der Objektkredit setzt sich wie folgt zusammen:
1. mehrbändige moderne Zuger Kantonsgeschichte im Umfang von 5,675 Millionen Franken;
2. Aufbereitung und Veröffentlichung digitaler Inhalte der Kantonsgeschichte im Umfang von 0,788 Millionen Franken;
3. Vermittlungsarbeit im Umfang von 0,532 Millionen Franken.
3 Der Objektkredit wird auf der Basis von 106,4 Punkten (August 2023) gemäss Landesindex der Konsumentenpreise bewilligt (Dezember 2020: 100 Punkte).
