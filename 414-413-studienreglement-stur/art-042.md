# § 42 Nachbesserung
1 Wird eine Bachelorarbeit mit der Note 3.5 oder der Note 3 bewertet, ist eine einmalige Nachbesserung innerhalb der von der Prüfungskommission gesetzten Frist möglich.
2 Wird eine Bachelorarbeit mit einer Note unter 3 bewertet, muss die Bachelorarbeit neu verfasst werden.
3 Wird eine nachgebesserte oder neu erarbeitete Bachelorarbeit erneut mit einer ungenügenden Note beurteilt oder unterbleibt eine Nachbesserung, dann schliesst die Hochschulleitung die Studentin oder den Studenten vom Studium aus.
