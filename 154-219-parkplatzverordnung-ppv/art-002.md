# § 2 Gebührenpflichtiges Parkieren
1 Im Rahmen des Parkplatzangebotes kann gegen eine monatliche Gebühr von
a) Fr. 160.– in einer Einstellhalle, bzw. Fr. 100.– im Freien parkieren, wer weder Gebührenfreiheit noch Gebührenreduktion gemäss diesem Reglement beanspruchen kann;
b) Fr. 200.– auf einem persönlich zugeteilten Parkplatz in einer Einstellhalle bzw. Fr. 120.– auf einem persönlich zugeteilten Parkplatz im Freien parkieren, wer weder Gebührenfreiheit noch Gebührenreduktion gemäss diesem Reglement beanspruche kann;
c) Fr. 80.– in einer Einstellhalle bzw. Fr. 50.– im Freien parkieren, wer mindestens fünf Arbeitstage pro Monat entweder Schicht- oder Pikettdienst leistet oder wer sein Privatfahrzeug für Sondereinsätze benötigt;
d) Fr. 100.– auf einem persönlich zugeteilten Parkplatz in einer Einstellhalle bzw. Fr. 60.– auf einem persönlich zugeteilten Parkplatz im Freien parkieren, wer mindestens fünf Arbeitstage pro Monat entweder Schicht- oder Pikettdienst leistet oder wer sein Privatfahrzeug für Sondereinsätze benötigt.
2 Für tageweises Parkieren im Freien zu privaten Zwecken während der Arbeitszeit können Tageskarten zum Preis von Fr. 10.– pro Karte bezogen werden.
